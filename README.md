# my-agent

An OpenCode-based agent scaffold.

## Structure

```
my-agent/
├── AGENTS.md                  # Agent behavior guidelines
├── PERSONA.md                 # Mentor voice and principles
├── KNOWLEDGE.md               # Domain knowledge index
├── .opencode/
│   ├── agents/
│   │   └── mentor.md         # Mentor agent definition
│   └── skills/
│       └── github-workflow/
│           └── SKILL.md      # GitHub workflow skill
└── README.md
```

## Usage

Open this directory with OpenCode; the `mentor` agent and `github-workflow` skill load from `.opencode/`.
